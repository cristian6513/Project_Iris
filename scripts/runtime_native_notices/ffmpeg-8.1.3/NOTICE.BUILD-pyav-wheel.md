# PyAV 17 private LGPL FFmpeg wheel

The exact unmodified PyAV sdist and FFmpeg source are included alongside pins. Run build_pyav_wheel.py --inputs INPUTS --python-archive PYTHON_ARCHIVE --ffmpeg-sdk FFMPEG_SDK --msvc MSVC_ROOT --windows-sdk SDK_ROOT --output NEW_OUTPUT. Inputs are the pinned PyPI wheels and sdist. Build FFmpeg first using its included source/pins/build instructions. Use the public MSVC and Windows SDK versions and hashes recorded in pyav-build-receipt.json. A fresh CPython is extracted from the archive; no global install or dependency resolution occurs. The script normalizes LIBRARY lines in copies of exported .def files, runs lib.exe /MACHINE:X64 /Brepro, setup.py --ffmpeg-dir=<private mirror> build_ext bdist_wheel, and delvewheel repair --add-path <private mirror/bin>. /Brepro /DEBUG:NONE and SOURCE_DATE_EPOCH=1790713770 are applied.

The LGPL FFmpeg libraries remain separately replaceable shared libraries. To replace them or modify FFmpeg, rebuild the SDK and this binding, then rerun delvewheel repair so import names and private loader match. No x264/x265 or other external codec libraries are bundled. PyAV is BSD-3-Clause; FFmpeg LGPL-2.1-or-later; MinGW and GCC runtime notices and GCC exception are included under av/licenses/ffmpeg. The compiler and build tools are build inputs and are not redistributed in this wheel.
