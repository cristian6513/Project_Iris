# Ejemplos de transiciones

Tres ejemplos originales, cada uno en CSS y JSON de Iris. El aviso MIT completo
viaja dentro de ambos formatos. La [guía de contribución](../../docs/guides/theme-transitions.md)
describe el contrato, los límites, la importación y el validador común.

- `entrada-suave`: desplazamiento vertical y escala suave.
- `zoom-sereno`: entrada centrada con escala y opacidad.
- `giro-sutil`: desplazamiento y giro breve con una ligera recuperación.

No contienen código ejecutable, recursos remotos o acceso a servicios.
